GOOD TO KNOW

A few common questions.

Are MeowTools free to use?

Yes. The tools are offered free to use. Optional support is never required to use a tool.

Are my files uploaded?

Tools that process files locally in your browser do not need to upload those files. Behavior can differ by tool, so read the individual tool page and do not assume every feature works the same way.

Do I need to create an account?

No account is required to start using the tools on this static website.

Why is a tool not working on my device?

Some browser features depend on the browser, file type or device. Try a current browser and check the tool's instructions.
