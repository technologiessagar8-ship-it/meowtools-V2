How to use

PNG is a lossless format that supports transparency. JPG is a small, widely supported photo format that uses lossy compression. Select your PNG files and download the JPG versions.

FAQ

Does PNG to JPG lose quality?

Converting to JPG is lossy but quality stays high. Transparency is kept only when the output format supports it.

Are my files uploaded?

No. Conversion happens locally in your browser.
