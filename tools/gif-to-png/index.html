How to use

GIF is an older format; only the first frame is converted. PNG is a lossless format that supports transparency. Select your GIF files and download the PNG versions.

FAQ

Does GIF to PNG lose quality?

Converting to PNG keeps the visible quality. Transparency is kept only when the output format supports it.

Are my files uploaded?

No. Conversion happens locally in your browser.
