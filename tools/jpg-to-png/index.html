How to use

JPG is a small, widely supported photo format that uses lossy compression. PNG is a lossless format that supports transparency. Select your JPG files and download the PNG versions.

FAQ

Does JPG to PNG lose quality?

Converting to PNG keeps the visible quality. Transparency is kept only when the output format supports it.

Are my files uploaded?

No. Conversion happens locally in your browser.
