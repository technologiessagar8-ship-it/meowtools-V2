Resize Photo or Signature for Online Forms

Set exact pixel size and a maximum KB for photo or signature uploads.

How to use

Enter the size your form asks for. Requirements change, so always check the official notification first. The image is center-cropped to fit.

FAQ

Which size should I enter?

Use the width, height and KB limit stated on the form you are filling.

What if the size is still too big?

Lower the pixel size a little and try again.
