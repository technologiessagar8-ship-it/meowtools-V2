DEPLOY:
1. Extract this ZIP.
2. Open the inner folder named MeowTools-Premium-Animated.
3. Upload/commit the CONTENTS of that folder to the ROOT of your GitHub repository (not the outer folder itself).
4. Commit to the branch configured for GitHub Pages.
5. Test the published site URL, not file:///... local path, because relative paths and browser restrictions may differ locally.

Note: This is a static GitHub Pages site. It has no backend. Tool processing remains client-side where supported by the existing tool implementation. This package has not undergone full real-browser QA for every tool.
